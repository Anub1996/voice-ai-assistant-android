How the estimate works: generating a token reads every active weight from memory once, so speed ≈ bandwidth × efficiency ÷ model size (efficiency ≈ 60% on CPU, 75% on GPU). The fit check counts the weights, a q8_0 KV cache for the chosen context, about 0.6 GiB of compute buffers, and 2.5 GiB kept free for your OS. Real numbers vary by about ±25%.
